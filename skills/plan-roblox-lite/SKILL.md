# Plan Roblox Lite: Streamlined Reverse Engineering & Master Prompt

This skill scans any decompiled Roblox map and produces a lightweight, essential-only Master Prompt focusing on 4 core tabs (Main Farm, Key Teleports, Player Movement, Anti-AFK/Safety) designed for high performance on mobile devices.

## Strict Formatting Directive
- DO NOT use any emojis anywhere in the output, GUI titles, or code comments. Keep all output strictly professional and emoji-free.

## Trigger Syntax
```text
/plan-roblox-lite <folder_path>
```
Example:
```text
/plan-roblox-lite C:\Users\Administrator\AppData\Local\Potassium\workspace\scripts_124216119978534
```

---

## Execution Protocol
1. Run `scan_roblox.ps1` on `<folder_path>`.
2. Output the streamlined Lite Master Prompt (4-tab layout, essential remotes, built-in safety).
3. Offer quick script generation: User can reply with `go th` (Thai) or `go en` (English).
